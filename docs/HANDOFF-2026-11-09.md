## 2. Track B: Research paper (this repo)

### 2.1 Topic
**"Cross-Platform vs Native: A Performance Benchmark of On-Device Deep Learning Inference in
Flutter and Native Android/iOS Applications."**
Gap: almost no controlled research on how much performance Flutter loses (or doesn't) when
running on-device AI compared with native code, using the same runtime and model.

### 2.2 Design decided
- **Runtime:** LiteRT (TensorFlow Lite) on all platforms (ADR-0002).
- **Platforms:** Flutter (`tflite_flutter`) vs native Android (Kotlin); iOS (Swift) optional if
  an iPhone/Mac is available (ADR-0003).
- **Models:** MobileNetV3 (classification), EfficientDet-Lite0 (detection), MobileBERT (QA);
  FP32 + INT8. (YOLOv8n is a candidate but has AGPL licensing concerns.)
- **Delegates:** CPU (XNNPACK), GPU, NNAPI.
- **Devices:** 2–3+ Android phones (low/mid/high tier), borrowed from friends if needed.
- **Metrics:** inference latency, end-to-end latency with stage breakdown (pre/inference/post),
  cold start, RAM (PSS), CPU %, battery drain (energy proxy), FPS, APK size.
- **Protocol:** 20 warm-up + 100 measured iterations × 5 sessions, randomised order, cooldown,
  airplane mode, fixed brightness, release builds only.
- **Statistics:** median/p5/p95, Mann–Whitney U, Holm correction, Cliff's delta, bootstrap 95% CI
  of the median ratio (ADR-0005).
- **Publishing:** arXiv preprint first (target end-Feb 2027) → Pakistani IEEE conferences (ICOSST,
  FIT, ICET, INMIC; verify CFPs) → may count as the university's mandatory research paper (confirm with supervisor).
- **Writing rule:** AI can help with code; the author writes and understands the analysis and prose.
