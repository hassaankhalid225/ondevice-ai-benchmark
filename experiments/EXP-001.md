## Run notes & empirical observations
1. **Device Identification:**
   Infinix Hot 8 (MT6765 Helio P22 octa-core Cortex-A53 up to 2.0 GHz, PowerVR Rogue GE8320 GPU, Android 9 API 28).
2. **Schema & Protocol Parity:**
   - Both Android Native and Flutter outputs validate 100% against `benchmark-spec/result-schema.json` v1.1.
   - Total records collected in Session 1: 2,413 measurement records across 33 files.
   - `output_digest` verification: MobileBERT QA on prompt 0 produced identical `qa:5-5` digest on both Flutter and Native Android.
3. **Hardware & Delegate Findings:**
   - **GPU Delegate:** Successfully ran on PowerVR GE8320 via OpenCL / OpenGL ES for `fp32` models (`efficientdet_lite0_fp32_gpu`, `mobilebert_qa_fp32_gpu`, `mobilebert_qa_int8_gpu`). For `mobilenetv3_large_int8` and `fp32`, GPU delegate initialization returned `unsupported` due to PowerVR driver kernel limitations.
   - **NNAPI Delegate:** On Android 9 (API 28), LiteRT NNAPI delegate executed for `fp32` and `int8` on Native Android, falling back to CPU partitions when drivers lacked acceleration. On Flutter Dart FFI, NNAPI was recorded as `unsupported` conforming to specification.
4. **Latency Profiles (Session 1 Medians):**
   - EfficientDet-Lite0 FP32 GPU: Native = 53.3 ms native inference vs. Flutter = 54.1 ms native inference (Bridge overhead: ~0.8 ms).
   - MobileBERT QA FP32 GPU: Native = 53.5 ms vs. Flutter = 53.4 ms.
   - MobileBERT QA INT8 CPU: Native = 116.2 ms vs. Flutter = 77.7 ms.

## Deviations from protocol
- NNAPI delegate in `tflite_flutter` Dart FFI bindings is not supported on Android 9 API 28; properly caught, logged, and emitted with `status: "unsupported"` per schema specification.
- Initial pilot run had 3 configs interrupted during manual detach; covered in subsequent automated run.
