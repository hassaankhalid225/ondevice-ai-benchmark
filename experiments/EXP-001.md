## Key Empirical Findings ($N=8$ Session Medians + $n=10$ Baseline)

- **RQ1 (`inference_native_ms`):** Complete statistical and practical parity across all 4 shared GPU configs ($\mathcal{R} = 0.99\text{--}1.04$, $|\delta| \le 0.31$, $p_{\mathrm{Holm}} = 1.000$; `mobilenetv3_large` GPU rejected by PowerVR GE8320 on both stacks). Default CPU configs favor Flutter on `mobilebert_qa fp32` (`116.02` vs `232.80 ms`, $\mathcal{R} = 0.50 [0.39, 0.69]$, $p_{\mathrm{Holm}} = 0.003$) and `efficientdet_lite0 fp32` (`101.80` vs `136.45 ms`, $\mathcal{R} = 0.75 [0.50, 0.86]$, $p_{\mathrm{Holm}} = 0.042$) due to `litert 1.4.0`/`2.20.0` default single-thread XNNPACK outperforming TFLite `2.16.1` 4-thread contention (ADR-0009). Native-only NNAPI shows API 28 CPU fallback (`79.48–225.69 ms`).
- **RQ2 (`end_to_end_ms`, `preprocess_ms`, `boundary_overhead_ms`, `postprocess_ms`):** Pure Dart `image` decoding (`68.53–103.17 ms` vs Native `8.64–24.56 ms`, $4.20\times\text{--}10.48\times$, $p_{\mathrm{Holm}} \le 0.036$) drives up to $2.00\times$ (`156.13` vs `77.99 ms`, FP32 GPU) and $1.91\times$ (`176.17` vs `92.33 ms`, INT8 GPU) slowdowns on EfficientDet-Lite0. FFI marshalling stays `<5 ms` (`0.88–4.63 ms` vs `0.21–1.47 ms`), though recursive `[1, 384]` logit copies on `mobilebert_qa` produce $11.90\times\text{--}18.22\times$ ratios and add $+4.90\text{ ms}$ ($1.09\times$, $p_{\mathrm{Holm}} = 0.008$) on FP32 GPU. Postprocessing stays `<0.2 ms` ($<0.3\%$).
- **RQ3 (`pss_mb`, `idle_pss_mb`, `cpu_pct`):** Flutter adds $+37.99\text{ MiB}$ settled idle baseline (`71.29` IQR `0.52` vs `33.30` IQR `0.25 MiB`, $2.14\times [2.13, 2.16]$, $p_{\mathrm{Holm}} = 0.003$) AND $+7.24$ to $+83.18\text{ MiB}$ higher *incremental* inference PSS (`1.25x–3.06x` Native incremental PSS; total steady state `107.86–200.36 MiB` vs `55.77–86.64 MiB`, $1.72\times\text{--}2.64\times$, all $p_{\mathrm{Holm}} \le 0.024$) due to `Model.fromBuffer()` `calloc` copies and Dart decode buffers. Host CPU is higher on Flutter GPU runs (`2.55–2.63x` vision) due to Dart preprocessing, and higher on Native MobileNetV3 CPU (`153.3–184.7%` vs `59.1–68.0%`) due to 4-thread XNNPACK.
- **RQ4 (Interactions):** Across mixed modalities, Spearman $\rho(\text{Native inf}, \text{E2E ratio}) = -0.39$ ($p = 0.260$); Flutter non-kernel share drops from $60.9\%\text{--}65.3\%$ (GPU vision) to $3.0\%\text{--}3.4\%$ (CPU NLP). Switching CPU $\to$ GPU exposes Dart preprocessing ($\mathcal{R}=1.17 \to 2.00$ on EfficientDet FP32) and stretches shader break-even from 32 Native to 114 Flutter inferences (`10` vs `28` on MobileBERT FP32). INT8 helps CPU ($25.8\%\text{--}56.7\%$ faster, $18\%\text{--}27\%$ lower Flutter PSS) but slows PowerVR GE8320 GPU by $12.3\%\text{--}27.0\%$.
- **RQ5 (`cold_start_ms`, `model_load_ms`, APK size):** Flutter cold-launch `TotalTime` is `468.50 ms` (IQR `10.75`; `WaitTime 518.5 ms`) vs Native `423.00 ms` (IQR `20.50`; `WaitTime 461.0 ms`), $\mathcal{R} = 1.11 [1.05, 1.14]$, $\delta = +0.92$, $p_{\mathrm{Holm}} = 0.005$. CPU model load is $3.74\times\text{--}11.71\times$ slower on 5–22 MB models (`103.93` vs `8.88 ms` MobileNet FP32) due to `calloc` buffer reading vs `mmap`, while GPU shader init equalizes both (`1.63–4.20 s`). Universal APKs measure `123.83 MB` vs `65.63 MB`; single-ABI `arm64-v8a` non-model footprint is `24.06 MB` vs `7.27 MB` (`+16.79 MB`).
