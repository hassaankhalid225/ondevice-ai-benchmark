# EXP-002 · Controlled Runtime/Threading Reruns, `fromFile` Control, and Multi-Device Runbook

- **Status:** READY FOR HARDWARE EXECUTION (on branch `exp-002`)
- **Spec / ADR:** ADR-0010 (`litert:1.4.0` / C `2.20.0` aligned across both stacks)
- **Target Devices:**
  1. `dev-infinix-x650c` — Infinix Hot 8 (Android 9, API 28, Helio P22 MT6765) — controlled `1t`, `4t`, and `fromFile` arms
  2. **Infinix Smart 7** (`dev-infinix-...` from `benchkit devices`) — second device full suite + controlled CPU/loader arms

## Build & Install Check (Once Before Running)
```powershell
cd apps/flutter_bench; flutter build apk --release
cd ../android_native_bench; .\gradlew.bat assembleRelease
cd ../..

# Plug phone via USB Debugging, inspect exact device_id & serial:
python -m benchkit devices
python -m benchkit install
python -m benchkit check
```

## Arm 1 — Matched `LiteRT 2.20.0`, 1-Thread CPU (`Priority 1.1`, 6 configs x 8 sessions)
Runs CPU-only (`mobilenetv3_large`, `efficientdet_lite0`, `mobilebert_qa` x `fp32`, `int8`, `threads=1`, alternating platform order):
```powershell
1..8 | ForEach-Object {
  python -m benchkit run -d dev-infinix-x650c -k $_ --arm matched_1t --threads 1 --cpu-only
}
python -m benchkit validate data/raw/exp002/matched_1t
python -m benchkit summarize data/raw/exp002/matched_1t --out data/processed/exp002_matched_1t_summary.csv
python -m benchkit compare data/raw/exp002/matched_1t --out data/processed/exp002_matched_1t_comparisons.csv
```
